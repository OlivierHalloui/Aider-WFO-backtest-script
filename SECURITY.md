# Security Policy

## Supported versions
Only the latest `main` branch is considered actively maintained.

## Reporting a vulnerability
Do not open a public issue for security problems.

Please report vulnerabilities privately via GitHub Security Advisories:
1. Go to the repository on GitHub.
2. Open the `Security` tab.
3. Create a private vulnerability report.

If Security Advisories are not available, contact the maintainer directly and include:
- Reproduction steps
- Impact assessment
- Suggested remediation (if available)

## Secrets and credentials
- Never commit API keys, tokens, or passwords.
- Use environment variables or local secret files ignored by Git.
