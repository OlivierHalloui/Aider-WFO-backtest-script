# WFO Engine (WFOE)

Application principale d'optimisation Walk-Forward (WFO).

## Lancement

Depuis la racine du repo:

```bash
streamlit run apps/wfo_engine/app.py
```

Ou via launcher:

```bash
./scripts/run_wfoe.sh
```

## Dépendances

```bash
pip install -r apps/wfo_engine/requirements.txt
```

## Tests

```bash
pytest -q apps/wfo_engine/tests
```
